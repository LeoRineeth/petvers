# petvers
1️ . Overview


PetVerse is a browser-based virtual pet simulation game developed using Python (Flask) for backend and HTML, CSS, and JavaScript for frontend.

The application allows users to create, manage, and interact with virtual pets in a dynamic game environment.


It includes:

Real-time pet status updates

Coin economy system

Level progression

Daily rewards

Job/work mechanics

Shop system

Persistent data storage

The system combines object-oriented backend logic with a web-based interactive interface.

 2️ . Objective


The primary objective of PetVerse is:

To simulate a virtual pet ecosystem with progression mechanics.

To implement real-world game design principles like:

Resource management (coins)

Time-based decay system

Reward systems

Leveling and evolution

To demonstrate backend–frontend integration using Flask.

To apply Object-Oriented Programming concepts in a real application.

To create a deployable full-stack web project suitable for GitHub and hosting platforms.

In short:

PetVerse is designed to merge game logic, web development, and OOP concepts into a single interactive project.
